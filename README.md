# Immersive Nuclear - addon for Immersive Engineering

## Description
Immersive Nuclear brings nuclear technologies tiered to the game, with a focus on realism and immersion. It is designed to be compatible with Immersive Engineering and other mods. The mod includes a variety of nuclear reactors, fuel types, and waste management systems.

## Features
- **4 types of Nuclear Reactors**: MSR, FNR, VVR and RBMK
- **Steam separator**
- **Steam turbine**
- **Cooling tower**
- **Heat exchanger**
- **Electrolyzer**
- **Nuclear waste re-processing**
- **EV energy tier**
- **New materials and components**
